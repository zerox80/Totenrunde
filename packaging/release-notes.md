Rundenbasierter Zombie-Überlebensmodus im Stil von *Black Ops 2*, geschrieben in Rust mit Bevy.
Alle Modelle, Texturen, Geräusche und das Licht sind selbst erzeugt.

## Herunterladen und starten

| System | Datei | Starten |
|---|---|---|
| **Windows 10/11** (64 Bit) | `Totenrunde-…-windows-x64.zip` | Entpacken, `Totenrunde.exe` doppelklicken |
| **Linux** (64 Bit) | `Totenrunde-…-linux-x64.tar.gz` | Entpacken, `Totenrunde` doppelklicken |

- Das Archiv **vollständig entpacken**. Das Spiel braucht den Ordner `assets` neben der Programmdatei.
- Windows warnt beim ersten Start, weil das Spiel nicht signiert ist: **Weitere Informationen → Trotzdem ausführen**.
- Linux: Optional legt `./desktop-eintrag.sh` einen Startmenü-Eintrag an.
- Benötigt eine Grafikkarte mit Vulkan oder DirectX 12. Ruckelt es, im Menü unter **GRAFIK** eine niedrigere Stufe wählen.

Steuerung und weitere Hinweise stehen in `LIESMICH.txt` im Archiv.
